# 🎤 CantaÊ Karaokê

Landing page responsiva desenvolvida para o **CantaÊ Karaokê** (Mônica & Sil), um negócio de karaokê para eventos — festas particulares, aniversários, casamentos e confraternizações corporativas.

🔗 **Demo online:** [cantaekaraoke-monicaesil.netlify.app](https://cantaekaraoke-monicaesil.netlify.app)

## 📋 Sobre o projeto

O objetivo foi transformar a divulgação do negócio (antes limitada a uma arte para redes sociais) em uma presença digital profissional, responsiva e com contato direto via WhatsApp — facilitando a conversão de visitantes em clientes.

## ✨ Funcionalidades

- Layout 100% responsivo (mobile-first)
- Botão de WhatsApp com seleção entre dois atendentes e mensagem pré-preenchida
- Botão flutuante de WhatsApp fixo durante a rolagem
- Navbar fixa que aparece ao rolar a página
- Seção de perguntas frequentes (FAQ) em formato acordeão
- Animações de entrada nas seções ao rolar a página (Intersection Observer)
- Meta tags de SEO e Open Graph para compartilhamento em redes sociais
- Favicon próprio

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura semântica
- **CSS3** — Flexbox, Grid, variáveis CSS, animações e media queries (sem frameworks)
- **JavaScript** (vanilla) — interações de UI e Intersection Observer
